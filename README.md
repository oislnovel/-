# 日本語読み上げ

GitHub Pagesでそのまま公開できる、最小構成の日本語読み上げアプリです。

## 機能

- 本文貼り付け欄
- 文字数表示
- 音声選択
- 読み上げ
- 停止

Windows Edgeでは、OSにインストールされている Microsoft Ayumi などの日本語音声が音声選択に表示されます。

## 公開方法

1. このリポジトリをGitHubへpushします。
2. GitHubの **Settings → Pages** を開きます。
3. **Source** で `Deploy from a branch` を選び、ブランチと `/ (root)` を選びます。
4. 表示されたGitHub Pages URLを開きます。
